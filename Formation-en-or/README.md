# Une famille en or
Ajouter une question : créer `questions/q-XXXX.json` (copier un exemple), puis `node scripts/build-index.js`.
Tester en local (le chargement des JSON exige un serveur) : `python3 -m http.server 8000` puis http://localhost:8000
Couleurs : variables `--ign-*` en tête de `css/style.css` (valeurs à aligner sur la charte IGN).
